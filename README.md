# DDL → ER-диаграмма

Откройте `index.html` в браузере, вставьте PostgreSQL DDL и нажмите **Построить**.
Предпросмотр показывает те же таблицы, строки и начальные маршруты линий, что и
экспорт. Нажмите **Скачать .drawio** и откройте файл в diagrams.net через
**Файл → Открыть с устройства**. Линии закреплены за ячейками столбцов. В строках выделены `PK`, `FK`,
`NULL` и `NOT NULL`. Crow’s Foot показывает обязательность по nullable-статусу
FK и верхнюю границу кратности по первичным и уникальным ограничениям.
Таблицы сгруппированы по связанным компонентам и разложены слева направо
от родительских таблиц к зависимым.

Страница работает локально, включая разбор SQL. Для запуска готового файла
достаточно браузера с WebAssembly. SQL никуда не отправляется.

Поддерживаются `CREATE TABLE` и добавление первичных и внешних ключей через
`ALTER TABLE [ONLY] … ADD CONSTRAINT`. Составной FK отображается одной линией
на пару столбцов. Имя ограничения доступно при наведении на линию.
Для имён без схемы используется `public` либо единственная подходящая таблица
из DDL, если в `public` её нет. Настройки `search_path` и команды клиента
`psql` находятся за рамками поддерживаемого формата.

## Сборка

С Node.js 22 или новее выполните:

```sh
npm ci
npm run build
```

Сборка встраивает JavaScript, WASM и лицензионные уведомления в `index.html`.
Парсер — [libpg-query](https://github.com/constructive-io/libpg-query-node).
Схема с дочерними ячейками столбцов следует подходу
[sqltooling-drawio](https://github.com/funktechno/sqltooling-drawio).

## Правки в draw.io

Экспорт использует нативные таблицы draw.io. Чтобы добавить поле, выделите ячейку
существующей строки и используйте команду вставки строки выше или ниже в панели
таблицы. В новой строке отдельно заполните ключ, имя, тип и nullable-статус.
Сохраните изменения в файле `.drawio`.
